Where does it break?

Where does it break?

Output Quality Depends
on the Ticket

  • The issue is the agent’s entire “prompt”
  • A vague ticket will lead to a hallucination and guessing
  • More time must be spent on writing more detailed tickets
Where does it break?

No Persistent Memory

  • Each session starts fresh, with no memory of earlier sessions or conversations
  • Has to rediscover the context from the branch and commit history
  • Decisions made by the team outside of Linear will not be captured unless it is written down somewhere
  • Long, multi-step work is more fragile than one small task
Where does it break?

Reviewing Becomes
the Bottleneck

  • Every PR still needs to be reviewed by a human
  • Delegating too much just shifts the workload instead of reducing it
  • Code reviews need to be as rigorous as with any teammate
Where does it break?

Limited Environment

  • Without Docker or a database in its environment, it cannot run the app or a browser
  • UI behaviour is verified purely by reading the code
  • Still need humans to conduct manual tests
