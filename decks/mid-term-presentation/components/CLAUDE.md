# components/ (deck-local) — Claude instructions

Components only this deck needs, or overrides of a shared component (same folder name wins over `/components`).
Same format as shared components: `<name>/<name>.html` + `<name>.css`, root class `c-<name>`, theme tokens only.
If a local component turns out to be reusable, move it to the root `components/` and document it there.
