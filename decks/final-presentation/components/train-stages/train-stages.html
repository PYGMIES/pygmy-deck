A separate Trainer builds the challenger. The app only sends links and tracks progress.

1

Export

One Parquet file in Storage. Trader emails become a one-way code. Read back, checksum recorded.

A frozen file, no personal data leaving.
2

Hand-off

The app calls the Trainer with 4 time-limited download and upload links (valid 2 hours).

The Trainer never gets database access.
3

Train

Downloads the data and the champion, checks the data, trains the challenger, scores both on the same TEST trades, uploads the model and predictions.

Live scoring continues as normal.
4

Track

A loop in the API asks the Trainer for progress every 30 s. On success the challenger is registered as an inactive model.

Over 2 hours, the run is marked failed.

Storage dataset · model · predictions
